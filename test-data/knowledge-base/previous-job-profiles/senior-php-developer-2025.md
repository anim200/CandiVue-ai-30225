# Previous Job Profile: Senior PHP Developer (2025)

**Example Freight Ltd. (fictional company, synthetic test document)**
Hired: 2025 · Team: Shipment Tracking · Status: filled

## About the role

The Shipment Tracking team builds the APIs that tell customers where their
parcels are. The Senior PHP Developer owned the tracking API and its database,
and mentored two junior developers.

## Responsibilities

- Design and build REST APIs in Laravel for the tracking and billing services
- Keep the MySQL database fast: indexes, query reviews, migrations
- Run every service in Docker, locally and in production
- Write automated tests (PHPUnit, Pest) and review pull requests
- Work with the mobile team on API contracts
- Take part in the on-call rotation after six months

## Requirements we used

- Mandatory: PHP 8, Laravel, Docker
- Required: MySQL or PostgreSQL, Git, REST API design, automated testing
- Preferred: AWS certification, Redis, queues (Laravel Horizon), CI/CD pipelines
- Minimum experience: 5 years of professional PHP development

## What worked in hiring

- Candidates who had run Laravel in Docker (or Laravel Sail) settled in fastest.
- Asking about a real performance problem they had fixed told us more than
  trivia questions.
- A short take-home task was dropped: it put off strong candidates with
  families. A live 30-minute code review worked better.
