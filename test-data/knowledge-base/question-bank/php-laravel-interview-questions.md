# Interview Question Bank: PHP and Laravel Backend

**Example Freight Ltd. (fictional company, synthetic test document)**
Questions used in earlier interviews, grouped by what they check.

## Laravel

1. A Laravel API endpoint became slow after a new feature. How would you find
   the cause? (Looks for: query log, N+1 queries, eager loading, indexes.)
2. When would you move work into a queued job instead of doing it in the
   request? Give an example from your own work.
3. How do you change a large production table with a migration without
   downtime?
4. How do you structure validation and authorisation in a Laravel API?
   (Form requests, policies, gates.)

## PHP

5. What changed for you when moving a project from PHP 7 to PHP 8?
6. How do you handle errors and exceptions so that the API returns useful
   messages but never leaks internal details?

## Docker and deployment

7. Walk me through the Docker setup of a project you worked on. Which services
   ran in which containers?
8. A container works on your laptop but fails in CI. What do you check first?
9. How do you keep secrets such as database passwords out of images and
   repositories?

## Databases

10. How do you decide which columns to index? Tell me about an index that made
    a big difference.
11. Explain a time you had to fix bad data in production.

## Teamwork

12. Tell me about a code review where you disagreed with a colleague. What
    happened?
13. How do you help a junior developer who is stuck?

## Company-related

14. Our engineers work three days a week in the office. How does that fit your
    situation?
15. What would you like to learn in your first year with us?
